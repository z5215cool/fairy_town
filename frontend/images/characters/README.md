# 角色图片模板说明

## 目录结构

将角色图片放置在 `frontend/images/characters/` 目录下。

## 预设角色图片列表

### 基础角色（必须）

1. **小红帽** - `xiaohongmao.png`
   - 用途：小红帽、小红等角色
   - 建议尺寸：200x200 像素

2. **奶奶** - `nainai.png`
   - 用途：奶奶、老太太、外婆等角色
   - 建议尺寸：200x200 像素

3. **大灰狼** - `dahui lang.png`
   - 用途：大灰狼、灰狼、狼等角色
   - 建议尺寸：200x200 像素

4. **妈妈** - `mama.png`
   - 用途：妈妈、母亲等角色
   - 建议尺寸：200x200 像素

5. **爸爸** - `baba.png`
   - 用途：爸爸、父亲等角色
   - 建议尺寸：200x200 像素

### 扩展角色（可选）

6. **猎人** - `lieren.png`
7. **王子** - `wangzi.png`
8. **公主** - `gongzhu.png`
9. **巫婆** - `wupo.png`
10. **精灵** - `jingling.png`
11. **巨人** - `juren.png`

## 图片要求

- **格式**：PNG（支持透明背景）
- **尺寸**：建议 200x200 像素
- **风格**：建议统一为卡通/插画风格
- **背景**：透明背景或纯色背景

## 如何添加新角色模板

1. 准备角色图片文件（PNG 格式）
2. 将图片文件放入 `frontend/images/characters/` 目录
3. 在 `app.js` 的 `getCharacterImageTemplate()` 函数中添加映射关系

示例：
```javascript
'新角色名': 'images/characters/xin juese.png',
```

## 图片来源建议

- 使用 AI 绘画工具生成（如 NanoBanana）
- 使用免费素材网站（如 Unsplash、Pixabay）
- 自行绘制或委托画师创作

## 注意事项

- 如果图片文件不存在，系统会自动显示默认图标（👤）
- 角色名称支持中英文匹配
- 支持模糊匹配（角色名包含关键词即可）
