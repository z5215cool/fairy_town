# 童话镇多智能体系统 - 使用说明

## 系统简介

童话镇多智能体系统是一个交互式的前端界面，支持用户输入小说文本或剧本，实现角色识别、角色扮演、可视化交互及剧情预测功能。系统采用现代化的UI设计，提供直观友好的用户体验。

## 系统要求

### 浏览器要求
- Chrome 90+ (推荐)
- Firefox 88+
- Safari 14+
- Edge 90+

### 系统要求
- 支持HTML5的现代浏览器
- JavaScript已启用
- 屏幕分辨率建议：1280x720或更高

## 快速开始

### 1. 启动系统

#### 方法一：使用Python内置服务器
```bash
# 在项目目录下运行
python -m http.server 8080
```

#### 方法二：使用Node.js
```bash
# 安装http-server
npm install -g http-server

# 启动服务器
http-server -p 8080
```

#### 方法三：直接打开
双击 `index.html` 文件，在浏览器中打开即可（部分功能可能受限）

### 2. 访问系统

在浏览器中访问：`http://localhost:8080`

## 功能指南

### 1. 故事输入

#### 输入故事文本
1. 在右侧"故事输入"面板中找到文本输入框
2. 输入或粘贴您的故事文本或剧本内容
3. 支持中文、英文等多种语言

#### 加载示例故事
1. 点击"加载示例"按钮
2. 系统会自动填入一个示例故事（小红帽的故事）
3. 您可以基于此示例进行修改和测试

#### 清空文本
1. 点击"清空文本"按钮
2. 确认清空操作
3. 文本输入框将被清空

### 2. 文本分析

#### 分析角色
1. 在文本输入框中输入故事内容
2. 点击"分析文本"按钮
3. 系统会自动识别故事中的角色、场景和剧情点
4. 分析结果会显示在"角色识别"面板中

#### 查看识别结果
- 识别到的角色会显示在右侧"角色识别"面板
- 每个角色显示名称、角色类型和识别置信度
- 角色会自动添加到左侧的角色列表和场景中

### 3. 角色管理

#### 查看角色列表
- 左侧面板显示所有识别到的角色
- 每个角色卡片显示头像、名称和角色类型
- 鼠标悬停在角色卡片上会高亮显示

#### 选择角色
1. 点击角色卡片
2. 选中的角色会高亮显示
3. 系统状态栏会显示当前选中的角色

#### 角色交互
1. 点击角色卡片上的"交互"按钮（对话框图标）
2. 打开角色交互面板
3. 可以与角色进行对话

#### 刷新角色
1. 点击角色列表上方的"刷新"按钮
2. 角色列表和场景中的角色会重新渲染

### 4. 场景可视化

#### 查看场景
- 中间区域显示童话镇场景
- 包含天空、地面、城堡、树木等元素
- 角色会以动画形式显示在场景中

#### 场景控制
- **放大**: 点击放大镜图标，放大场景视图
- **缩小**: 点击缩小镜图标，缩小场景视图
- **重置**: 点击主页图标，恢复默认视图

#### 查看角色位置
- 角色在场景中以图标形式显示
- 角色名称标签显示在角色下方
- 角色会自动浮动动画

### 5. 角色移动

#### 使用控制面板
1. 选择要移动的角色
2. 使用场景下方的移动控制按钮
3. 点击方向按钮（上、下、左、右）移动角色
4. 角色会在场景中移动到新位置

#### 使用键盘快捷键
- **↑**: 向上移动
- **↓**: 向下移动
- **←**: 向左移动
- **→**: 向右移动

#### 移动限制
- 角色不能移出场景边界
- 移动距离为固定步长
- 支持连续移动

### 6. 角色动作

#### 执行动作
1. 选择角色
2. 点击动作控制按钮
3. 角色会执行相应动作

#### 支持的动作
- **走路**: 角色执行走路动作
- **说话**: 角色执行说话动作
- **跳舞**: 角色执行跳舞动作

### 7. 角色对话

#### 与角色对话
1. 点击角色卡片上的"交互"按钮
2. 打开角色交互面板
3. 在对话框中输入对话内容
4. 点击"发送"按钮
5. 角色会自动回复

#### 查看对话历史
- 对话历史显示在交互面板中
- 用户消息显示在右侧
- 角色回复显示在左侧
- 支持滚动查看历史对话

### 8. 剧情预测

#### 生成预测
1. 输入故事文本并分析
2. 点击"生成预测"按钮
3. 系统会生成多个可能的剧情发展方向

#### 查看预测结果
- 预测结果显示在"剧情预测"面板
- 每个预测包含标题、描述和可能性
- 点击预测选项可以查看详情

#### 选择剧情分支
1. 点击任意预测选项
2. 系统会记录您的选择
3. 可以基于选择继续发展故事

### 9. 系统设置

#### 打开设置
1. 点击顶部导航栏的"设置"按钮
2. 打开设置模态框

#### 可设置项目
- **界面主题**: 选择童话主题、暗色主题或亮色主题
- **动画效果**: 启用或禁用角色动画
- **音效**: 启用或禁用音效（需要后端支持）
- **自动保存**: 启用或禁用自动保存功能

#### 保存设置
1. 修改设置项
2. 点击"保存设置"按钮
3. 设置会立即生效并保存到本地存储

### 10. 新故事创建

#### 创建新故事
1. 点击顶部导航栏的"新故事"按钮
2. 确认创建新故事
3. 当前内容将被清空
4. 系统重置到初始状态

## 使用技巧

### 1. 高效的角色识别
- 使用明确的角色名称（如"小红帽"而不是"女孩"）
- 在文本中多次提及角色名称可以提高识别准确率
- 使用标准的角色类型词汇（主角、反派、配角）

### 2. 优化场景描述
- 在文本中明确描述场景（如"在森林里"、"在城堡前"）
- 使用具体的场景名称可以提高场景识别准确率
- 场景描述会影响角色的初始位置

### 3. 提升对话质量
- 使用自然语言与角色对话
- 提供足够的上下文信息
- 避免过于简短的对话

### 4. 有效使用剧情预测
- 在故事关键节点生成预测
- 比较不同预测的可能性
- 选择最符合故事发展的预测

### 5. 系统性能优化
- 关闭不必要的动画效果
- 定期清空对话历史
- 使用自动保存功能避免数据丢失

## 常见问题

### Q: 为什么角色识别不准确？
A: 
- 使用更明确的角色名称
- 在文本中多次提及角色
- 检查文本格式是否正确

### Q: 角色移动不流畅怎么办？
A: 
- 检查浏览器性能
- 关闭动画效果
- 减少同时移动的角色数量

### Q: 如何保存当前故事？
A: 
- 启用自动保存功能
- 系统会自动保存到本地存储
- 下次打开时会自动加载

### Q: 剧情预测不准确怎么办？
A: 
- 提供更详细的故事文本
- 确保角色信息完整
- 尝试重新生成预测

### Q: 系统在移动设备上如何使用？
A: 
- 系统支持响应式设计
- 在移动设备上会自动调整布局
- 建议使用横屏模式获得更好体验
